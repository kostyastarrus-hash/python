# Практикум по Python

Учебные задачи, решённые в рамках курса «Информационные системы и программирование».
Репозиторий пополняется по мере прохождения практики.

## Список задач

| Файл | Задача | Темы |
|------|--------|------|
| lesson01/task01_variables.py | Работа с переменными и типами данных: цепное присваивание, арифметика, повторение списка | переменные, float, списки, операции *= |
| lesson01/task02_minutes_to_hours.py | Перевод минут в часы и остаток минут | целочисленное деление //, остаток % |
| lesson01/task03_divisible_by_three.py | Проверка делимости двух чисел на 3 (оба / одно / ни одного) | оператор %, логические операторы and/or |
| lesson01/task04_check_punctuation.py | Проверка, содержит ли строка символы "." и "," одновременно | ввод, оператор in, ветвление if/else |
| lesson01/task05_sleep_control.py | Контроль продолжительности сна: недосып / норма / пересып | условные конструкции if/elif/else |
| lesson01/task06_absolute_value.py | Вывод модуля введённого числа | условные операторы, арифметика |
| lesson01/task07_heron_triangle_area.py | Площадь треугольника по формуле Герона с проверкой существования | функции, import math, f-строки |
| lesson01/task08_shape_area.py | Вычисление площади фигуры: прямоугольник, треугольник, круг | ввод, строковые методы lower(), ветвление |
